# StatusMaxing

StatusMaxing is a Java application for a college software development course. The idea is a simple gamified life and finance tracker. A user can enter basic personal and financial information, and the app calculates values like BMI, net worth, a financial standing tier, a status score, and the probability of reaching a savings goal.

## Project Design

The starting class design for the project is in [statusmaxing.puml](statusmaxing.puml). The UML diagram shows the main classes, their fields and methods, and how they relate to each other. It covers the core logic only and does not include JavaFX or other graphical components.
